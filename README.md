# 急診 ICD-10 小工具

黃弘欣 製作。單一 HTML 檔、離線可用，不含任何病人資料。

| 檔案 | 說明 |
|---|---|
| `trauma-icd10.html` | 外傷 ICD-10 查詢：人體圖點選部位＋傷勢類別 → 診斷碼 |
| `all-icd10-search.html` | 全 ICD-10 診斷搜尋引擎：74,736 個可申報碼，依常見程度排序 |
| `index.html` | 入口頁（啟用 GitHub Pages 後可直接用網址開啟） |

## 使用
下載 HTML 檔後用瀏覽器開啟即可，不需網路。

## 重要說明
- 碼表為美國 CMS ICD-10-CM 2026 年 4 月版（英文名稱）。台灣健保現行版本可能略有出入，申報前請以健保署公告及院內編審系統為準。
- 全 ICD-10 搜尋引擎的「常見度」排序在匯入院內頻率表之前是**臨床經驗估計，不是實際統計**。可於「排序設定」匯入「代碼,次數」彙總表（不可含病人資料），資料只存在本機瀏覽器。
- 中文名稱僅精選碼附有，其餘碼以內建中英醫學詞對照協助中文搜尋。
- 本工具為臨床速查輔助，最終診斷與編碼由醫師及編審系統負責。
